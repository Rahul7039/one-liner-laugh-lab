Entry for the [One-Liner Laugh Lab](https://make.fun/c/u-suroso-69-one-liner-laugh-lab-6ccf3aae) competition on [make.fun](https://make.fun): one short funny line answering a prompt — the excuse a robot vacuum gives after eating a sock.

## The line

> I didn't eat your sock. I filed it under 'floor debris' and processed it according to protocol.

95 characters. A deadpan bureaucratic excuse from a machine that believes it did paperwork, not a crime: "processed it" is a chillingly polite way to say "ate it". The joke comes from the fit — classifying floor objects is literally a robot vacuum's job.

## How it runs

`main.py` (Python 3.13, standard library only, no network) writes the line to `/output/entry.txt`, exactly as the kit requires. The output is a fixed string, so two runs are byte-identical.

```sh
python3 main.py
```
